* Virtual FS

VirtualFS is a declarative and safe file system operations script designed to handle file and directory manipulations in a virtual manner. Users can define a series of operations, such as creating directories (~mkdir~), creating files with content (~spit~), setting executable permissions, and deleting files (~rm~) or directories (~rmdir~), including recursive deletions. These operations are validated and accumulated without side effects until the ~mkvfs~ function is called, ensuring that all changes are applied atomically. This approach is particularly advantageous for testing environments, where operations can be verified in a mock directory before commiting, allowing for controlled, repeatable, and safe tests without affecting the actual file system.

** Change instructions vs VFS
A *change instruction* is a concise, descriptive map representing an intended file system operation, such as creating, deleting, or modifying files and directories. All FS operations produce change instructions.

Upon calling ~mkvfs~ on the change instruction list, a VFS is produced. VFS (Virtual File System) is a detailed map that models the current state of a file system, including the hierarchical structure of directories and files with their associated metadata. Change instructions describe planned operations, while the VFS represents the resulting file system state after applying those operations.

This instruction:
#+begin_src clojure
  {:path "a/b/c" :parents true :executable true :content "#!/bin/sh\necho Hello world!"}
#+end_src

Generates this VFS:
#+begin_src clojure
  {"a" {:type :directory}
   "a/b" {:type :directory}
   "a/b/c" {:type :file :executable true :content "#!/bin/sh\necho Hello world!"}}
#+end_src

Instructions can create and then delete, VFS is always the final state.

All the way up to here there we had no side-effects. This declarative way helps us to test the result VFS:

** Usage
*** In tests
#+begin_src clojure
  (ns myapp.test
    (:require [clojure.test :refer :all]
              [jakub-stastny.virtual-fs.core :as vfs]))

  ;; Return a list of changes.
  (def black-box []
    [(vfs/write "my/path/test-file.txt" "Hello, World!")])

  (deftest file-creation-test
    (let [vfs (mkvfs (black-box))
          test-file (get vfs "my/path/test-file.txt")]
      (is (= "Hello, World!") (:content test-file))))
#+end_src

** Implementation
#+begin_src clojure :tangle ../src/jakub_stastny/virtual_fs/core.clj :mkdirp yes :ns jakub-stastny.virtual-fs.core
  (ns jakub-stastny.virtual-fs.core
    (:require [clojure.string :as str]))

  (defn- create-change-instruction [type path & {:keys [content parents executable recursive] :or {parents false executable false recursive false}}]
    (let [base-change-instruction {:type type :path path}
          base-change-instruction (if parents (assoc base-change-instruction :parents true) base-change-instruction)
          base-change-instruction (if executable (assoc base-change-instruction :executable true) base-change-instruction)
          base-change-instruction (if recursive (assoc base-change-instruction :recursive true) base-change-instruction)]
      (if (= type :write-file)
        (assoc base-change-instruction :content content)
        base-change-instruction)))

  (defn mkdir [path & {:keys [parents] :or {parents false}}]
    (create-change-instruction :create-directory path :parents parents))

  (defn write
    [path content & {:keys [parents executable] :or {parents false executable false}}]
    (create-change-instruction :write-file path :content content :parents parents :executable executable))

  (defn rm [path]
    (create-change-instruction :delete-file path))

  ;; Note that to recursively delete a directory it's rmdir path :recursive true, not rm as it'd be on Unix.
  (defn rmdir [path & {:keys [recursive] :or {recursive false}}]
    (create-change-instruction :delete-directory path :recursive recursive))

  (defn validate-change-instruction [change-instruction]
    (let [{:keys [type path]} change-instruction]
      (when-not type
        (throw (ex-info "Change instruction must have a type" {:change-instruction change-instruction})))
      (when-not path
        (throw (ex-info "Change instruction must have a path" {:change-instruction change-instruction})))
      (when (and (= type :write-file) (not (:content change-instruction)))
        (throw (ex-info "Create file change instruction must have content" {:change-instruction change-instruction})))
      true))

  ;; (defn apply-change-instruction [change-instruction root]

  ;;       :write-file

  ;;         (when executable

  ;;       :delete-file
  ;;       (fs/delete full-path)

  ;;       :create-directory

  ;;       :delete-directory
  ;;       (if recursive
  ;;         (fs/delete full-path {:recursive true})
  ;;         (fs/delete full-path)))))

  (defn apply-change-to-vfs [vfs change]
    (let [{:keys [type path content parents executable recursive]} change]
      (letfn [(split-path [path]
                (let [chunks (str/split path #"/")]
                  (map #(str/join "/" (take % chunks)) (range 1 (inc (count chunks))))))
              (add-directories [vfs dirs]
                (reduce (fn [acc dir]
                          (assoc acc dir {:type :directory}))
                        vfs
                        dirs))]
        (case type
          :write-file
          (let [dirs (if parents (butlast (split-path path)) [])
                new-vfs (add-directories vfs dirs)]
            (assoc new-vfs path {:type :file :content content :executable executable}))

          :create-directory
          (let [dirs (if parents (split-path path) [path])]
            (add-directories vfs dirs))

          :delete-file
          (dissoc vfs path)

          :delete-directory
          (if recursive
            (reduce (fn [acc [k v]]
                      (if (str/starts-with? k path) acc (assoc acc k v)))
                    {}
                    vfs)
            (dissoc vfs path))))))

  (defn mkvfs [change-instructions]
    (when (every? validate-change-instruction change-instructions)
      (reduce apply-change-to-vfs {} change-instructions)))

#+begin_src clojure :tangle ../src/jakub_stastny/virtual_fs/adapters/babashka_fs.clj :mkdirp yes :ns jakub-stastny.virtual-fs.babashka-fs
  (ns jakub-stastny.virtual-fs.adapters.babashka-fs
    (:require [clojure.string :as str]
              [babashka.fs :as fs]))

  (defn create-directory [full-path opts]
    (println (str "~ [D] " full-path " " (pr-str opts)))
    (fs/create-dir full-path opts))

  (defn create-file [full-path {:keys [content executable] :as opts}]
    (println (str "~ [F] " full-path " " (pr-str opts)))
    (spit full-path content)
    (when executable
      (fs/set-posix-file-permissions full-path (fs/posix-file-permissions "rwxr-xr-x"))))

  (defn commit [vfs root-path]
    (fs/create-dirs root-path)
    (doseq [[path {:keys [type] :as opts}] vfs]
      (let [full-path (str/join "/" [root-path path])
            opts (dissoc opts :type)]
        (case type
          :directory (create-directory full-path opts)
          :file (create-file full-path opts)))))
#+end_src
